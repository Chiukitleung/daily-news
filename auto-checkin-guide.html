📱 手机自动打卡 · 保姆级教程

把一部手机放在公司，到点自动帮你打卡（钉钉 / 企业微信 / 飞书通用）
苹果篇 + 安卓篇，按需选择，全程无需改定位、无需越狱（安卓）/免越狱（苹果）

前提：手机常驻公司 · 定位天然真实 · 纯本地自动化
00先搞清楚一个关键点
不同平台的自动化能力差别很大，方向选错会白折腾。
能力🍎 iPhone🤖 Android
程序化模拟点击（不越狱/不 root）不支持 系统封闭支持 无障碍服务即可
定时自动打开打卡 App支持 快捷指令支持 多种方式
最省事的"极速打卡"两边都支持 到公司范围自动打卡（前提：公司开启了该功能）
全自动（打开+点击）部分 需配合极速打卡完全 脚本全流程
💡 先查这个：不管安卓还是苹果，先看你公司打卡 App 有没有开「极速打卡 / 快捷打卡」——钉钉、企业微信、飞书都有这个功能。开着的话，手机放公司 什么教程都不用看，到点自动就打上了。下面的教程是"没开极速打卡 / 想 100% 按点打"的完整方案。
01苹果方案总览
iPhone 系统封闭，不能像安卓那样模拟点击。靠谱路线只有一条：快捷指令在固定时间打开打卡页 → 页面自动完成打卡（极速打卡）或你手动点一下。锁屏状态下无法自动打开 App（系统硬限制），所以手机要设成充电时保持亮屏 / 不锁屏。
方案难度效果适用
A. 快捷指令 + 极速打卡简单全自动（到点开 App 即自动打卡）公司开了极速打卡 → 首选
B. 快捷指令定时唤起打卡页简单到点自动打开打卡页，需手动点一下「打卡」公司没开极速打卡 → 保底方案
C. 越狱 + AutoTouch 录制点击高全自动真点击不推荐：失去保修、易失效、有封号风险
02准备工作（一次搞定）
以下 3 件事是苹果方案的前提，做完就不用再管。
1
手机设置：关闭自动锁屏 / 充电时保持亮屏
设置 → 显示与亮度 → 自动锁定 → 选「永不」（或「充电时保持唤醒」）。锁屏状态下快捷指令无法打开 App，这是苹果方案的唯一硬条件。
2
打卡 App 里开启「极速打卡」（能开就开）
钉钉：考勤打卡 → 右上角设置 → 开启「极速打卡」；企业微信：工作台 → 打卡 → 右上角「...」→ 上下班打卡设置 → 开「快捷打卡」；飞书：工作台 → 勤假 → 打卡设置 → 开「自动打卡」。开启后，手机到公司范围且打卡页在前台时自动完成打卡。
3
复制打卡页的应用链接（URL）
打开打卡 App → 工作台 → 找到「打卡 / 考勤 / 勤假」→ 长按该图标 → 分享 → 复制链接（或选「应用链接」）。这个链接就是一会儿快捷指令要打开的地址，先粘贴到备忘录存好。
03创建快捷指令自动化（10 分钟）
1
打开「快捷指令」App → 底部「自动化」标签
iPhone 自带应用，无需安装任何东西。
2
点右上角「＋」→「创建个人自动化」→ 选「特定时间」
时间设为上班打卡前 5 分钟（如 8:55），重复选「每天」。
3
添加操作：搜索「打开 URL」或「在 Safari 中打开」
把第 02 步复制的打卡页链接粘贴进去。
4
关掉「运行前询问」⚠️ 关键一步
保存时的开关页里，把 「运行前询问」关掉（会弹"不询问"确认点掉）。不关的话到点不会自动跑，会停下来等你确认，就失去意义了。
5
保存，再建一个「下班」的自动化
同样流程再建一条 18:00（或你下班时间）的。想模拟随机延迟防"每天同一秒"：自动化的操作里先加「随机数」1–180，再加「等待」该秒数，再打开 URL。
✅ 做成什么样：每天 8:55 手机自动亮起并打开打卡页。如果公司开了极速打卡，打开页面瞬间已自动打卡成功；没开的话，页面已停在你面前，点一下「打卡」即可（这是苹果能做到的最好程度）。
04注意事项
⚠️ 锁屏限制：快捷指令自动化在锁屏状态无法打开 App（苹果系统限制，无解）。所以手机必须保持亮屏（充电常亮 / 永不锁屏），屏幕长期亮着记得给手机配个定时息屏保护或放在不显眼处。
⚠️ 越狱方案不建议：网上有"越狱 + AutoTouch"全自动版，但越狱后打卡 App 可能检测环境风险、系统更新易失效，为了打卡不值得。
💡 通知亮屏辅助：如果嫌屏幕常亮费电，可在「自动化」里加一步「打开 App 前先发一条通知」配合系统「通知亮屏」——但稳定性不如直接常亮，日常使用推荐充电常亮（手机放公司充电就行）。
01安卓方案总览
安卓开放生态，免 root 就能做到全自动（定时打开 App + 自动点击打卡按钮 + 失败通知）。三条路线任选，推荐 A。
方案难度效果适用
A. Auto.js 本地定时脚本简单全自动，手机本地跑，不依赖网络首选：主流可靠，社区案例多
B. 电脑/服务器 ADB 远程驱动中等全自动，可远程操控、截图验证已有 Linux/Windows 常开机器的人
C. 现成打卡 App（如 DailyTask）简单全自动 + 远程指令不想碰脚本：装 App 填时间即用
02方案 A · Auto.js 脚本自动打卡（推荐）
Auto.js 是安卓上的自动化脚本引擎，通过「无障碍服务」模拟点击，不需要 root。GitHub 上有大量现成打卡脚本可直接抄。

① 安装与授权（一次搞定）

1
安装 Auto.js 或 AutoX.js（开源版）
AutoX.js 可直接从 GitHub 下载 APK（搜索 AutoX.js github）。安装后打开，它需要「无障碍服务」权限：系统设置 → 无障碍 → Auto.js → 开启。晚上台手机也可以，Android 8~16 都支持。
2
防止被杀后台：电池白名单 + 自启动
设置 → 应用 → Auto.js → 电池 →「无限制」；允许自启动。否则系统省电机制会杀掉定时任务。
3
锁屏策略：滑动解锁 / 无密码锁
脚本要能点亮屏幕，锁屏设成滑动解锁（无密码）最简单；或开启「通知亮屏」。有密码锁的话脚本解不开。

② 打卡脚本（核心）

以下为通用脚本骨架，把 App 包名和打卡按钮文字换成你实际的（钉钉包名 com.alibaba.android.rimet，企业微信 com.tencent.wework，飞书 com.ss.android.lark）：
// 上班自动打卡（Auto.js） var pkg = "com.alibaba.android.rimet"; // 换成你的打卡App包名 var btnText = "打卡"; // 打卡按钮上的文字 device.wakeUpIfNeeded(); // 点亮屏幕 sleep(500); app.launchPackage(pkg); // 打开打卡App sleep(6000); // 等页面加载（低端机调到8000） if (text(btnText).findOne(10000)) { // 按文字找按钮，10秒超时 text(btnText).findOne().click(); // 点击打卡按钮 toastLog("打卡成功 ✅"); } else { toastLog("没找到打卡按钮 ❌"); // 可加截图保存，方便排查 } home(); // 退回桌面

③ 定时执行（两步）

1
在 Auto.js 里运行脚本一次，确认能正常打卡
先手动跑通再交给定时。识别不到按钮时：用 Auto.js 的「布局分析」看按钮真实文字，或改成 desc(btnText) / id(...)。
2
用 Tasker 或 Auto.js 定时任务绑定脚本
Auto.js 内置「定时任务」：把脚本设为每天 8:55 / 18:00 执行；或用 Tasker 的「时间」触发器调用脚本。加 1–3 分钟随机延迟可避免每天同一秒打卡（写脚本时在点击前 sleep(随机数) 即可）。
✅ 完成效果：手机放公司充电，每天到点自动亮屏 → 打开钉钉 → 自动点打卡 → 退回桌面。全本地运行，断网也能打。
💡 现成脚本直接抄：GitHub 搜 AutoDingDing、DingDing-Automatic-Clock-in、AutoCheckinPlugin（企业微信）——都是免 root 的成熟打卡项目，下载脚本改下配置就能用。
03方案 B · 电脑 ADB 远程驱动（进阶）
手机开「无线调试」，电脑（或任何常开机器）通过 adb 连接后定时跑 Python 脚本。好处：远程可控、打卡截图可验证、失败可通知。

① 手机开启无线调试

1
开发者选项 → 无线调试 → 开启
设置 → 关于手机 → 连点「版本号」7 次打开开发者选项。无线调试里能看到「IP 地址:端口」。
2
首次配对
电脑执行 adb pair 手机IP:配对端口 输入配对码（无线调试详情页有六位码），再 adb connect 手机IP:连接端口。授权一次性，之后永久有效；手机重启后端口会变，需重新 connect（放公司的手机不常重启，影响很小）。

② Python + uiautomator2 打卡脚本

import uiautomator2 as u2 import datetime d = u2.connect("手机IP:端口") # 无线调试的地址 d.wakeup() # 点亮屏幕 d.app_start("com.alibaba.android.rimet", use_monkey=True) d.app_wait("com.alibaba.android.rimet", timeout=15) if d(text="打卡").exists(timeout=10): d(text="打卡").click() d.screenshot(f"clock_{datetime.date.today()}.png") # 截图存证 print("✅ 打卡成功，截图已保存") else: print("❌ 没找到打卡按钮")
3
定时执行
Windows 用「任务计划程序」每天 8:55 跑 python clock_in.py；Linux 用 crontab：55 8 * * * python3 /path/clock_in.py。脚本里加失败判断 + 企业微信/Server酱推送通知即可远程感知。
✅ 适用：你已经有一台常开的电脑/服务器（本教程作者就是把这套跑在服务器上，还能顺便每天生成打卡截图）。手机不需要 root，连接授权一次搞定。
04方案 C · 现成打卡 App（零脚本）
不想碰任何代码的话，有开源 App 装好填时间就能用。
1
DailyTask（GitHub 搜索 AndroidCoderPeng/DailyTask）
定位就是「备用手机放公司工位，设好上下班时间自动打卡」。免 root、不改 GPS、本地运行；支持微信小号远程指令触发。兼容 Android 8~16 和鸿蒙 4.0。
2
按 App 引导授权无障碍服务 → 设置打卡时间 → 放公司
这类 App 本质也是无障碍自动点击，把包名/时间填对即可。注意同样要加电池白名单防杀。
05安卓注意事项
⚠️ 杀后台：90% 的"定时没跑"问题都是脚本进程被系统杀掉了。Auto.js / Tasker 都要：电池无限制 + 自启动 + 最近任务里加锁，个别用小米澎湃系统的可能还要额外设置。
⚠️ 锁屏：用滑动解锁（无密码），或开「通知亮屏」。有 PIN/图案锁的话，点亮屏幕后脚本点击会被锁屏拦截。
⚠️ 检测风险：root 过的手机用打卡 App 可能提示「设备风险」，需要 Magisk DenyList 隐藏——所以没 root 的普通手机反而最干净。免 root 方案不存在这个问题。
💡 蓝牙考勤机：如果公司用蓝牙考勤机，手机保持蓝牙常开即可，脚本流程不变（有现成项目支持）。
99最后：所有平台通用提醒
这页不讲技术，讲边界。
⚠️ 合规：自动打卡本质是"手机在、人可能不在"。公司考勤规则通常要求本人到岗，被查到可能算违纪。手机放在公司、定位真实，但操作者不是本人——用之前自己掂量，出了事自己负责。本教程仅供技术交流。
✅ 最优先方案永远是官方功能：钉钉/企业微信/飞书的极速打卡（到公司范围自动打卡）＋手机放公司＝零折腾零风险。教程里所有自动化都只是这个功能的补充和兜底。先问公司 HR 有没有开极速打卡！
💡 贴心建议：手机放公司记得插着充电器、开勿扰模式、放包里或抽屉里（亮屏状态屏幕朝下）。下班自动化同理，一条指令复用就行。
